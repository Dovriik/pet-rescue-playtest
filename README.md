# Pet Rescue public playtest

Build 0.5.0-playtest.2026-11-16; 50 campaign levels, two lessons and Zen.

Open the published GitHub Pages link and press Play. No installation or account is needed. Mouse and touch are supported. Progress is stored locally in the current browser on this device. Clearing site data or using private browsing may remove progress.

This early playtest has no real payments, ads, accounts, leaderboard or cloud saves. Tell the person who shared it your level number, device/browser and what happened when reporting a problem.

The repository contains the exported playtest, not the development workspace or personal save data. Deployment retrieves the pinned engine from the official Godot release and checks its archive and runtime checksums before publishing an ordinary index.wasm. Local upload bundles also include verified engine parts. The browser loads standard Godot files.
